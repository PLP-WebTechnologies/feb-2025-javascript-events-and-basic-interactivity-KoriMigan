JavaScript Events

Events are actions or occurrences that happen in the browser which the JavaScript can detect and respond to. Common events include:

  • Mouse events: click, dblclick, mouseenter, mouseleave
  • Keyboard events: keydown, keyup, keypress
  • Form events: submit, change, focus, blur
  • Document/Window events: load, resize, scroll, unload

Event listeners are used to "listen" for when these events happen and execute code in response.

DOM Manipulation

The Document Object Model (DOM) represents the structure of HTML documents as a tree of objects. JavaScript can:

  • Select elements using methods like getElementById, querySelector
  • Change element content with innerHTML or textContent
  • Modify attributes using setAttribute and getAttribute
  • Change styles with the style property
  • Add/remove classes with classList methods
  • Create, append and remove elements dynamically

Form Validation

Client-side form validation ensures data is in the correct format before submitting to a server. Key techniques include:

  • Required fields: Ensuring fields aren't left empty
  • Data format: Checking email addresses, phone numbers, etc.
  • Data range: Verifying values fall within expected ranges
  • Real-time validation: Providing immediate feedback as users type
  • Custom validation: Creating specific rules for your application

While client-side validation improves user experience, server-side validation is still necessary for security.
